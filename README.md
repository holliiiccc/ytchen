# Holly Chen portfolio

Static HTML, CSS, JavaScript, and media in `dist/`. No build command or package installation is required.

## Netlify

Connect this repository and use `dist` as the publish directory. Leave the build command empty. `netlify.toml` supplies the publish directory.

## Local preview

Run `python3 -m http.server 8766 --bind 127.0.0.1 --directory dist` from the repository folder, then open http://127.0.0.1:8766.

## Domain migration

Keep existing email DNS records when connecting holly-ytchen.com. Two Personify case studies still depend on Wix URLs; preserve or migrate them before cancelling Wix. Domain connection and domain registration transfer are separate tasks.
